# Ordinary route weight-detail limitation

The saved ordinary `/route` response for restriction relation 1645783 has a finite scalar route weight of **71.875759**, a distance of **328.843 m**, and duration **42280 ms**. Its `details.weight` array nevertheless starts with the JSON string `"Infinity"`; many later edge entries include an apparent extra 60 units. The foot response also has a string `"Infinity"` in its first weight-detail entry while its scalar route weight is finite **40.203867**. The raw responses are retained in [the car export](geometry-spot-checks/restriction-1645783-car.response.json) and [the foot export](geometry-spot-checks/restriction-1645783-foot.response.json).

In upstream [WeightDetails.java](../../core/src/main/java/com/graphhopper/util/details/WeightDetails.java), `isEdgeDifferentToLastEdge` assigns `edgeId = edge.getEdge()` and then calls `GHUtility.calcWeightWithTurnWeight(weighting, edge, false, edgeId)` (lines 46–47 in this checkout). The helper receives the current edge as the incoming edge. This explains the apparent U-turn contribution in these detail entries, including the configured 60-second car U-turn cost; a virtual-edge U-turn can instead be prohibited. The observed detail entries cannot be summed to validate the selected route's scalar weight or turn legality.

Matrix outputs use the selected predecessor's actual edge/turn metrics. Matrix differential diagnostics independently reconstruct the directed path and recompute its edge and turn contributions with the real previous edge. They do not use the ordinary `/route` `details.weight` array as an oracle. Scalar ordinary route metrics, street instructions, geometry, edge keys and access details remain separate recorded evidence.

No production upstream fix was made for this detail-export issue. The source and original responses are preserved. Geometry review can show the imported route's detour, but this observation does not certify real-world street legality. The regional source and importer limitations are documented in [osm-data-limitations.md](osm-data-limitations.md).
